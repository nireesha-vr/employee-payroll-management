# ResolvIO Enterprise - Complaint Resolution Platform

A high-density grievance and service desk platform designed for corporate compliance, customer grievance redressal, internal employee ticketing, and strict SLA management.

## ⚖️ Core Enterprise Features
- **High-Density Grievance Ledger**: Centralized oversight of complaints across HR & Payroll, Vehicle Logistics, Billing & Invoicing, IT Infrastructure, and Facilities.
- **SLA Countdown & Severity Categorization**:
  - `Critical`: 4-hour strict resolution SLA window
  - `High`: 12-hour resolution target
  - `Medium`: 24-hour resolution target
  - `Low`: 48-hour resolution target
- **Interactive Resolution Console**: Complete chronological audit trail showing who investigated, root-cause notes, reassignments, and state transitions.
- **One-Click Quick Actions**: Rapidly resolve complaints or reopen closed tickets with full timestamp logging.
- **Grievance Intake Engine**: Standardized intake modal with automatic SLA calculation and specialist desk assignment.
- **Multi-Parameter Search & Sort**: Filter by category, priority, status, or search through Ticket ID, subject, and requester names.
- **CSV Audit Ledger Export**: Generate complete historical ticket logs in CSV format for compliance reporting.
- **Persistent Local Database**: Automatically saves tickets to browser `localStorage` with a factory default reset option.

## 🚀 How to Run
Open `index.html` in any modern web browser.
