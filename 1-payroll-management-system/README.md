# CorpPay Enterprise - Payroll Management System

A high-density, corporate-grade enterprise web application for managing workforce payroll, compensation structures, statutory deductions, disbursement status tracking, and automated payslip generation.

## 💼 Core Enterprise Features
- **High-Density Ledger Table**: Crisp tabular overview displaying Employee ID, designation, department, basic salary, allowances, gross pay, deductions (EPF, TDS, Mediclaim), and net take-home pay.
- **Dynamic Compensation Calculation**: Real-time evaluation of gross salary, deductions, and net salary during data entry and updates.
- **Multi-Filter & Column Sort**: Real-time text search, department filter, approval status filter, and multi-directional column sorting.
- **Official Printable Salary Voucher**: Print-ready and PDF-exportable employee payslip with corporate header, statutory breakdown, and authorized signature placeholders.
- **Lifecycle Status Management**: Progress records seamlessly from `Draft` &rarr; `Approved` &rarr; `Paid` (Disbursed).
- **Bulk Batch Processing**: One-click batch processing to approve drafts and disburse verified payroll.
- **CSV Ledger Export**: Instant export of current payroll register to RFC-compliant CSV for accounting records.
- **Local Persistence**: Stores state safely in browser `localStorage` with built-in reset to seed data.

## 🚀 How to Run
Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari). Zero build tools or server setup required.
